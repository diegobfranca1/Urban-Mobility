# Dados do protótipo

`demo_zones.csv` é uma fixture **sintética e ilustrativa** para testar o aplicativo. Os nomes e coordenadas são aproximados, mas população e atratividade foram inventadas para demonstração; não representam estatísticas oficiais nem fluxos observados. Não cite os valores do demo como fatos sobre São Paulo.

Substitua por dados devidamente licenciados e documentados antes de qualquer uso analítico externo. Consulte o esquema em [`../docs/data-and-method.md`](../docs/data-and-method.md).
